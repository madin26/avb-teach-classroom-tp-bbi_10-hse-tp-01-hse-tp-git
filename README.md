## 📌 Описание

Скрипт `collect_files.sh` позволяет собрать **все файлы** из входной директории и всех вложенных поддиректорий (независимо от глубины) и скопировать их в **выходную директорию** — без вложенных папок, в виде простой плоской структуры.

Также реализована опция `--max_depth`, с помощью которой можно ограничить глубину обхода файловой структуры.

---

## ⚙️ Как использовать

> ⚠️ Убедитесь, что установлен Python версии 3 (на стенде тестирования доступна версия 3.12.3)

### 📄 Пример команды запуска:

```bash
./collect_files.sh input_dir output_dir [--max_depth N]
